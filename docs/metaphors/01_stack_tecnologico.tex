\chapter{Fundamentos y Metáfora del Sistema}

\section{Metáfora Conceptual: Centro de Operaciones de Red (NOC)}
La metáfora del sistema proporciona un modelo mental claro y unificado del funcionamiento de la plataforma:
\begin{itemize}
  \item \textbf{Consola de Visualización (Frontend):} Proyecta en pantallas interactivas el mapa de topología, indicadores clave de desempeño (KPIs) y el panel de alertas acústico-visuales.
  \item \textbf{Canal de Telemetría (WebSockets):} Enlace bidireccional continuo que transmite métricas y notificaciones en tiempo real sin requerir peticiones periódicas.
  \item \textbf{Centro de Control y Despacho (Backend API y Bus de Eventos):} Procesa peticiones administrativas seguras (autenticación JWT, gestión de usuarios, configuración) y gestiona el flujo asíncrono de eventos internos.
  \item \textbf{Motor de Sondeo (Servicio de Monitoreo):} Servicio autónomo en segundo plano que ejecuta comprobaciones periódicas de Capa 2 (ARP) y Capa 3 (ICMP ping) sobre los equipos registrados.
  \item \textbf{Almacén Central (MongoDB):} Repositorio documental que guarda inventario, métricas agregadas y bitácora histórica de eventos con políticas de retención automática (TTL).
\end{itemize}

La Arquitectura Dirigida por Eventos desacopla la detección de anomalías de su procesamiento y visualización, garantizando que el sistema reaccione en milisegundos sin bloquear el servidor web.

\chapter{Desglose Técnico del Stack Tecnológico}

\section{Componentes Seleccionados y Funciones}
A continuación se detalla la función técnica específica de cada tecnología seleccionada:

\begin{itemize}
  \item \textbf{React 18.2+ con Vite 5:} Interfaz reactiva concurrente. Actualiza el mapa de red y paneles métricos en tiempo real sin recargar la página.
  \item \textbf{Socket.io (v4.8 Backend / v4.7 Frontend):} Canal WebSocket persistente para transmisión bidireccional en tiempo real con reconexión automática y latencia inferior a 50 ms.
  \item \textbf{React Flow (@xyflow/react v12):} Motor de visualización para grafos interactivos de topología de red con nodos personalizados, aristas dinámicas, zoom y arrastre.
  \item \textbf{Node.js v20 LTS y Express v4.21+:} Entorno asíncrono no bloqueante con microframework para gestión de rutas REST, validación Zod y middlewares de seguridad (Helmet, CORS).
  \item \textbf{Bus de Eventos Interno (\texttt{EventEmitter}):} Despachador de mensajes en memoria que desacopla la captura de métricas, el motor de alertas y la persistencia.
  \item \textbf{Mecanismos de Red Nativos (\texttt{arp-scan} y \texttt{ping}):} Ejecución eficiente mediante procesos del kernel de Linux con pool de concurrencia (\texttt{p-limit} a 15 sockets simultáneos).
  \item \textbf{MongoDB 7.0 con Mongoose 8.9+:} Base de datos NoSQL documental con índices TTL para purga automática de sesiones y métricas históricas a 30 y 90 días.
  \item \textbf{Nginx 1.22+ y Systemd en Debian 12:} Servidor web inverso con terminación SSL y proxy WebSocket, orquestado como servicio nativo con política \texttt{Restart=always}.
\end{itemize}
